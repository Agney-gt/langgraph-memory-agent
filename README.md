This project demonstrates how to build a capable memory-augmented AI agent using LangGraph, Groq’s blazing-fast LLaMA 4 model, and Tavily Search, it's better than OpenAI’s Assistants API in context retention, speed, and cost-efficiency.

1. The Agent Takes in a Typescript Interface 
2. User inputs values one by one
3. Agent Outputs formatted JSON
